# Picture credits

All pictures in this folder are the **Flat** style of [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), used unmodified as SVG files and renamed by word (for example `dog.svg` is "Dog face").

License: MIT, Copyright (c) Microsoft Corporation. The full license text is in `LICENSE-fluentui-emoji.txt`.

On the site each picture gets a white sticker border and a glue shadow through CSS (`.sticker` in `src/app/globals.css`); the files themselves are not edited.
